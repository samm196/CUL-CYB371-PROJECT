## Fictional Student Dataset

-A Python program that creates a fictional dataset of five students.

## Fields
- Student ID
- Department
- Level
- Attendance percentage
- Average score

## How it works
- The user types the Student ID for each of the five students.
- The department, level, attendance and average score are generated randomly.
- Each student's details are printed on screen.
- All five students are saved to `student_dataset.csv`.

## How to run
1. Install Python 3.
2. Run `python students.py`.
3. Run on your code editor(e.g VS code)
4. Enter a Student ID when prompted, five times.

## Files
- `students.py`: the program
- `student_dataset.csv`: the generated dataset

All data is fictional.
